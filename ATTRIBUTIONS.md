# Attributions

## Bundled third-party content: none

Every file here is original prose, code or template material written for this skill. No
third-party file is redistributed, so no third-party copyright notice is required.

This file exists because that changes the moment someone bundles permissively-licensed
material, and the notice has to land here in the same commit.

## The rule

Facts, rules, schemas and APIs are not copyrightable — their *expression* is. So this skill
may freely state that `BaseSampleTime` is expressed in 100 ns ticks, or lay out the element
hierarchy of a `.tcscopex`, after learning both by reading real project files. It may not
paste those files in and call the result a template.

| Licence of a source | May this skill ship the file? |
|---|---|
| Permissive — MIT, 0BSD, BSD-2, MIT-0, Apache-2 | **Yes.** Record it in the table below. 0BSD needs no notice. |
| Copyrighted, or copyleft (GPL/LGPL) | **No.** Read it, restate in original words. Copying GPL code in would force this whole skill to GPL. |
| All rights reserved — vendor docs, blogs | **No.** Cite and link only; do not quote at length. |

The `.tcscopex` templates in `templates/` were **written from the observed schema**, not
copied from any sample. That is a deliberate choice: it keeps this table empty and avoids
inheriting anyone's notice requirements onto a file people will copy into their own projects.
